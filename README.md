# Скрипты MATLAB/Simulink для моделирования системы управления кожухотрубным теплообменником

Репозиторий содержит MATLAB-скрипты и Simulink-модели, использованные при выполнении выпускной квалификационной работы на тему: «Разработка системы управления процессом теплообмена в кожухотрубном теплообменнике».

## Назначение репозитория

Код использовался для выполнения расчётно-модельной части работы, связанной с проектированием и проверкой каскадной системы автоматического регулирования температуры продукта на выходе кожухотрубного теплообменника.

Скрипты применялись для:
- оценки чувствительности разомкнутого объекта по основным каналам;
- анализа внутреннего контура регулирования расхода пара;
- анализа внешнего контура регулирования температуры продукта;
- моделирования замкнутой системы при основных возмущающих воздействиях;
- сравнения номинального и загрязнённого объекта;
- расчёта запасов устойчивости внешнего контура;
- построения графиков переходных процессов.

## Структура репозитория

- `scripts/01_open_loop_sensitivity.m` — оценка чувствительности объекта в разомкнутом контуре.
- `scripts/02_inner_loop_metrics.m` — расчёт показателей качества внутреннего контура расхода пара.
- `scripts/03_outer_loop_metrics.m` — расчёт показателей качества внешнего контура температуры.
- `scripts/04_disturbance_product_flow.m` — моделирование возмущения по расходу продукта.
- `scripts/05_disturbance_inlet_temperature.m` — моделирование возмущения по входной температуре продукта.
- `scripts/06_disturbance_steam_pressure.m` — моделирование возмущения по параметрам греющего пара.
- `scripts/07_nominal_vs_fouled.m` — сравнение номинального и загрязнённого объекта.
- `scripts/08_stability_margins.m` — расчёт запасов устойчивости.
- `functions/` — вспомогательные функции для расчёта показателей качества.
- `models/` — Simulink-модели, использованные при моделировании.
- `figures/` — графики, полученные в результате расчётных экспериментов.

## Примечание

Скрипты разделены по расчётным задачам и соответствуют этапам моделирования, представленным в третьей главе ВКР. Отдельные файлы могут запускаться независимо, поскольку расчётные эксперименты выполнялись последовательно для разных сценариев моделирования.
